# Student Management System — Java + Spring Boot

A beginner-friendly student CRUD application built with Java 17, Spring Boot, Maven, Thymeleaf, Spring Data JPA and H2. MySQL configuration is included as an optional profile.

## Features
- Create, view, edit and delete student records
- Search by student name or email
- Automatic course eligibility calculation
- Dashboard counts for total and eligible students
- Form validation

## Requirements
- JDK 17 or later
- Maven 3.6+ (or use the Maven wrapper generated by your IDE)

## Run in the easiest mode (H2 database)
1. Extract the ZIP.
2. Open the `student-management` folder in IntelliJ IDEA or Eclipse as a Maven project.
3. Wait for Maven to download dependencies.
4. Run `StudentManagementApplication.java`, or in a terminal run:
   `mvn spring-boot:run`
5. Open http://localhost:8080

H2 is file-based and stores its data in the project's `data` folder. No separate database installation is needed.

## Use MySQL instead
1. Create a database (or let MySQL create it):
   `CREATE DATABASE student_management;`
2. Edit `src/main/resources/application-mysql.properties` and replace `YOUR_MYSQL_PASSWORD`.
3. Run:
   `mvn spring-boot:run -Dspring-boot.run.profiles=mysql`
4. Open http://localhost:8080

## How the Java backend works
- `Student` is the JPA entity mapped to the `students` table.
- `StudentRepository` talks to the database using Spring Data JPA.
- `StudentService` contains application operations.
- `StudentController` handles browser routes and sends data to Thymeleaf.
- Thymeleaf renders the HTML pages using values supplied by the controller.
